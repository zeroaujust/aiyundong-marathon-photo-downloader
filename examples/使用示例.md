# 使用示例

以下均为真实跑过的命令（2026 西青区半程马拉松 / 参赛号 B10426），按场景选用。

## 场景 1：标准下载（推荐，不漏照片）

```bash
python aiyundong_downloader.py --event "西青半程马拉松" --year 2026 --bib B10426
```

输出：

```
[赛事] 正在拉取平台赛事列表并匹配「西青半程马拉松 / 2026年」...
[赛事] 找到 1 个候选：
    1. [ID 36231] 【官方】2026新宇彩板西青区半程马拉松（约 195294 张照片）
[赛事] 唯一匹配，自动选择
[赛事] 平台档案：共 195294 张照片，视频 0 个
[赛事] 本赛事没有视频，所有「影像」均为照片
[号码搜索] 参赛号 B10426 ...
[号码搜索] 命中 47 张照片（平台原始计数 51，其余为广告占位）
[人脸] ...（每个脸一行：结果数 / 与号码重合数 / 是否本人）
[收敛过滤] 43 个本人人脸共同确认 92 张照片；保留人脸新增 46 张
[汇总] 参赛号命中 47 张 + 人脸新增 46 张 = 共 93 张
[完成] 共 93 张照片 -> ./马拉松照片_2026新宇彩板西青区半程马拉松_B10426
```

最终 93 张（小程序显示 92，多出的 1 张是号码已标注但人脸没认全的，保守保留）。

## 场景 2：多候选赛事，先列出再指定

```bash
# 第一步：列出候选
python aiyundong_downloader.py --event "西青" --year 2026 --bib B10426 --list-events

#   1. [ID 36231] 【官方】2026新宇彩板西青区半程马拉松（约 195294 张照片）
#   2. [ID 36420] 【官方】2026西青区秋季欢乐跑（约 11535 张照片）

# 第二步：指定 ID 下载
python aiyundong_downloader.py --event-id 36231 --bib B10426
```

## 场景 3：只要号码搜到的，快速拿一批

```bash
python aiyundong_downloader.py --event-id 36231 --bib B10426 --bib-only
```

跳过人脸阶段，约 1 分钟拿完 47 张。适合先看看有没有自己的照片。

## 场景 4：赛后几天增量更新

照片是陆续上传的。原样重跑同一条命令：

```bash
python aiyundong_downloader.py --event-id 36231 --bib B10426
```

日志里会看到「新增 N 张（已有 M 张，跳过）」，只下新的。

## 场景 5：自定义输出目录 + 高并发

```bash
python aiyundong_downloader.py --event-id 36231 --bib B10426 \
    --output "D:\我的照片\西青半马" --workers 16
```

## 场景 6：老赛事（分页翻深）

```bash
python aiyundong_downloader.py --event "北京马拉松" --year 2023 --bib A1234 --pages 20
```

## 场景 7：被限流时放慢请求

```bash
python aiyundong_downloader.py --event-id 36231 --bib B10426 --delay 1.5
```

## 场景 8：想连相貌相近的其他跑者照片一起拿（调试）

```bash
python aiyundong_downloader.py --event-id 36231 --bib B10426 --all-faces
```

会得到 145 张（含约 50 张误匹配），仅用于验证收敛过滤效果，日常别用。

## 场景 9：接入 AI 助手（自然语言）

装好 Skill 后直接对 AI 说：

> 「帮我把 2026 西青半程马拉松、参赛号 B10426 的照片下载到桌面，要带水印最高清的」

AI 会自动：匹配赛事 → 号码搜索 → 人脸补漏 → 收敛过滤 → 下载校验 → 报告数量。
