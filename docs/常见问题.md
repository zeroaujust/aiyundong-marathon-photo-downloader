# 常见问题（FAQ）

## 赛事相关

### Q1：搜不到我的赛事怎么办？

按以下顺序排查：

1. **关键词太长**。平台赛事名经常中间加赞助商，比如官方名是「【官方】2026新宇彩板西青区半程马拉松」，你搜「西青半程马拉松」反而匹配不到（中间多了「区」）。工具是按词元匹配的，但保险起见用**短关键词**：城市名 + 赛事类型，如 `--event "西青马拉松"` 或只写 `--event "西青"`。
2. **加年份**。`--year 2026` 能过滤掉往届同名赛事。
3. **翻更深的分页**。门户接口只返回最近的赛事，老赛事要 `--pages 20`（每页 100 条）。
4. **确认平台收录了这场比赛**。爱云动只收录部分赛事，去微信小程序里搜一下赛事名，搜不到就是这个平台没有。

### Q2：匹配到多个赛事，选哪个？

同城同期常有多个赛事（半马 / 欢乐跑 / 秋季跑）。先用 `--list-events` 看候选，根据照片总数和完整名称判断，然后用 `--event-id <ID>` 指定。不确定的话，去小程序点进每个赛事看看封面和照片数量。

### Q3：--event 和 --event-id 有什么区别？

`--event` 是模糊匹配（自动找赛事），`--event-id` 是精确指定（跳过搜索）。知道 ID 时用 `--event-id` 最快最准。

## 参赛号相关

### Q4：参赛号搜出来 0 张？

1. **检查号码格式**：字母大小写不敏感，但别多空格；注意 `0/O`、`1/I`、`5/S`、`8/B` 这些易混字符
2. **照片还没上传**：赛后才几小时，摄影师可能还没交片，过几小时或一两天再试
3. **赛事选错了**：用 `--list-events` 核对 ID
4. **号码没被标注**：极少数情况平台漏打了号码标签，这时人脸搜索也能补回（工具默认会做人脸搜索）

### Q5：号码格式是什么样的？

就是号码布上印的字符，如 `B10426`、`A1234`。前缀字母代表号码段（A/B/C…），不代表成绩区。

## 下载相关

### Q6：为什么下载的是带水印的？能下原图吗？

- 平台**免费开放的就是水印版**（最高清约 720×1080）
- 无水印原图需要在平台内**付费购买**（单张或套餐），这是摄影师的劳动成果
- 技术上把 URL 里的 `/img/watermark/` 去掉访问原图会 404，平台做了防护
- 本工具只下载平台免费开放的水印版，**不提供也不绕过付费**

### Q7：能去水印吗？

工具不管去水印。市面上有 AI 去水印工具，但请注意：水印是照片的版权标识，去水印后的照片请**仅自用**，不要传播或商用，否则可能侵犯摄影师著作权。

### Q8：下载很慢 / 中途失败？

- 调大并发：`--workers 16`
- 失败会自动重试 3 次；重跑整个命令会**断点续传**（跳过已下载的）
- 结尾的「校验」步骤会列出失败的 ID，重跑即可补下

### Q9：能增量更新吗？

能。照片是陆续上传的，过几天原样重跑同一条命令，搜到新照片会自动追加下载，已有的跳过。清单 `final_photos.json` 也会更新。

### Q10：输出目录能改吗？

`--output D:\马拉松照片` 指定任意目录。

## 人脸搜索相关

### Q11：人脸搜索为什么要上传照片？安全吗？

平台的人脸搜索接口要求图片先在平台自己的 OSS 上（`face_url` 必须是 OSS key，外部 URL 会被拒绝）。上传的是平台已经公开的照片本身，不涉及额外隐私信息；签名接口匿名可用（`uid=0`）。

### Q12：人脸阶段为什么慢？

要对每张号码照片做「上传 → 检测 → 搜索」三次调用，还要甄别多个人脸。47 张照片约 1-2 分钟，照片多的赛事（几百张）会久一些。想快就加 `--bib-only` 跳过。

### Q13：--min-faces 和 --overlap-threshold 是什么？

- `--overlap-threshold`（默认 15）：人脸搜索结果与号码结果的重合数，超过就认定这是「你本人」的脸（实测本人 ≥26，其他跑者 ≤7，15 是安全中间值）
- `--min-faces`（默认 2）：最终照片要被几个本人脸同时确认（实测按 2 过滤后总数与小程序显示一致）

一般不用动。如果发现漏照片，可以把 `--min-faces 1`；如果混入陌生人，调高 `--overlap-threshold`。

### Q14：下载出来的照片里有不认识的人？

把 `--min-faces` 调到 3 试试，或提高 `--overlap-threshold`。人脸匹配没有 100% 准确，工具已尽量在「不漏」和「不杂」之间平衡；你说一声「我自己挑」，所以默认偏保守。

## 报错相关

### Q15：`sign错误` / `status=-100`

签名计算与服务端不一致。本工具已按平台最新前端复刻，常见原因：

1. 改了脚本里的 `OSS_SIGN_SECRET`（应为 `iyd`）
2. `uid` 传了空串（本工具固定传 `"0"`）
3. 平台接口临时波动——重跑即可

### Q16：`-10000 服务器暂停服务`

视频搜索接口被平台暂停（部分赛事），这是平台侧限制。如果赛事本身没有视频（`search_summary.json` 或日志里 video=0），忽略即可。

### Q17：`HTTP 404`

路径写错了，或探测了不存在的接口。本工具只用文档中记录的接口；如果你在改代码，对照 [docs/原理说明.md](docs/原理说明.md) 第 2 节核对。

### Q18：`HTTP 500`

一般是缺必填参数（如 V1 接口不给 `uid` 会 500）。检查参数完整性。

## 其他

### Q19：支持跑步维生素、混沌影像等其他平台吗？

目前只支持爱云动/悦动拍系。扩展方法见 [docs/原理说明.md](docs/原理说明.md) 第 7 节，欢迎 PR。

### Q20：会被平台封号/限流吗？

工具全程匿名调用（`uid=0`）、默认 0.3s 间隔、单线程串行 API，与人工在小程序里翻页的负载相当。批量下载几百张图片属于正常使用。如遇限流，调大 `--delay`。
