# Wechat小程序-DY科技-马拉松水印照片批量下载工具

> 参加完马拉松，照片散落在微信小程序「爱云动」里几十页翻不完？这个工具帮你**按参赛号一键批量下载全部照片**（免费最高清水印版），并自动补回「人在照片里、但号码没被标注」的漏网照片。

适用平台：**爱云动 / 悦动拍（runnerbar）**——微信小程序「爱云动」及其 H5 站 `m.yundong.runnerbar.com`。国内绝大多数马拉松、越野跑、骑行赛的照片都收录在这个平台。

## 功能特性

- **赛事自动发现**：输入「哪一年的哪场比赛」（关键词），自动在平台赛事库里匹配，列出候选赛事
- **参赛号搜索**：按你的参赛号码（如 `B10426`）搜出平台收录的全部照片
- **人脸补漏**：自动对搜到的照片做人脸检测 + 人脸搜索，补回号码被遮挡/漏标注的照片——实测比单纯号码搜索多出一倍
- **智能去误匹配**：只有被 **≥2 个不同角度的本人人脸**共同确认的照片才保留，自动过滤其他跑者
- **批量高速下载**：多线程并发 + 失败自动重试 + 断点续传（重跑自动跳过已下载）
- **完整性校验**：逐张校验 JPEG 有效性，失败自动剔除并记录
- **缩略图总览**：一键生成带编号的缩略图拼版，快速浏览挑选
- **零依赖**：纯 Python 标准库实现，无需安装任何第三方包（Pillow 可选，仅用于总览图）

## 工作原理

```
┌─────────────┐   ┌──────────────┐   ┌───────────────┐
│ 1.赛事发现   │ → │ 2.参赛号搜索  │ → │ 3.人脸检测     │
│ 门户接口匹配 │   │ V2 搜索接口   │   │ 上传OSS+检测   │
└─────────────┘   └──────────────┘   └───────┬───────┘
                                             ↓
┌─────────────┐   ┌──────────────┐   ┌───────────────┐
│ 6.批量下载   │ ← │ 5.收敛过滤    │ ← │ 4.人脸搜索     │
│ 多线程+校验  │   │ ≥2脸确认才留  │   │ face_id 再搜   │
└─────────────┘   └──────────────┘   └───────────────┘
```

关键认知：**小程序里搜参赛号显示的数量，其实是「号码搜索 + 人脸匹配」合并的结果**。只调号码搜索接口只能拿到一半（比如小程序显示 92，号码搜索只有 47），另一半是「人在照片里但号码没被标注/遮挡」的照片，必须靠人脸搜索补回。详见 [docs/原理说明.md](docs/原理说明.md)。

## 安装

**要求**：Python 3.8 或更高版本，能访问互联网。

```bash
# 1. 下载本项目
git clone https://github.com/zeroaujust/aiyundong-marathon-photo-downloader.git
cd aiyundong-marathon-photo-downloader

# 2.（可选）安装 Pillow，用于生成缩略图总览和深度校验
pip install Pillow
```

> 不装 Pillow 也能正常下载，只是没有缩略图总览、图片校验只做文件头检查。

## 快速开始

**使用前请准备好三样信息：**

1. 📅 **哪一年的哪场比赛**——比如「2026 西青区半程马拉松」（用于匹配赛事）
2. 🔢 **你的参赛号码**——比如 `B10426`（号码布上的号码，注意字母数字）
3. 📁 **打算存到哪里**——默认存到当前目录下的 `马拉松照片_<赛事>_<参赛号>/`

```bash
# 最常用的命令：关键词 + 年份 + 参赛号
python aiyundong_downloader.py --event "西青半程马拉松" --year 2026 --bib B10426
```

第一次运行如果匹配到多个赛事（比如同城同期还有欢乐跑），工具会列出候选，你改用 `--event-id <ID>` 指定即可：

```bash
# 先看有哪些候选赛事（不下载）
python aiyundong_downloader.py --event "西青" --year 2026 --bib B10426 --list-events

# 输出示例：
#   1. [ID 36231] 【官方】2026新宇彩板西青区半程马拉松（约 195294 张照片）
#   2. [ID 36420] 【官方】2026西青区秋季欢乐跑（约 11535 张照片）

# 用 ID 直接下载
python aiyundong_downloader.py --event-id 36231 --bib B10426
```

## 参数说明

| 参数 | 必填 | 默认值 | 说明 |
|---|---|---|---|
| `--event` | 二选一 | - | 赛事名称关键词，如 `"西青半程马拉松"`、`"杭州马拉松"`。会按词元拆分匹配，写城市名+赛事类型即可 |
| `--event-id` | 二选一 | - | 已知赛事 ID 时直接指定，跳过搜索匹配 |
| `--bib` | ✅ | - | 参赛号码，如 `B10426` |
| `--year` | 推荐 | - | 赛事年份，如 `2026`。提供后只匹配该年份，避免同名赛事混淆 |
| `--output` | | `./马拉松照片_<赛事>_<参赛号>` | 输出目录 |
| `--list-events` | | 关 | 只列出匹配的赛事，不下载 |
| `--pages` | | 5 | 赛事列表拉取页数（每页 100 条）。老赛事搜不到时加大，如 `--pages 20` |
| `--bib-only` | | 关 | 只按参赛号搜索，跳过人脸搜索（快，但会漏照片） |
| `--all-faces` | | 关 | 不过滤人脸匹配（会混入其他跑者的照片，仅调试用） |
| `--min-faces` | | 2 | 收敛阈值：照片至少被几个本人人脸同时确认才保留 |
| `--overlap-threshold` | | 15 | 人脸归属判定：人脸搜索结果与参赛号结果的重合数达到该值才认定是本人 |
| `--limit-faces` | | 0（全部） | 只对前 N 张号码照片做人脸检测（调试用） |
| `--workers` | | 8 | 下载并发线程数 |
| `--delay` | | 0.3 | API 调用间隔（秒），被平台限流时调大 |
| `--no-sheet` | | 关 | 不生成缩略图总览 |

## 输出说明

```
马拉松照片_<赛事>_<参赛号>/
├── 001_8854943298939752706.jpg      # 照片：序号_平台照片ID
├── 002_...jpg
├── ...
├── 093_...jpg
├── final_photos.json                # 照片清单（来源、URL、尺寸、被几个人脸确认）
├── search_summary.json              # 搜索汇总（赛事、号码、各来源数量）
└── 缩略图总览.png                    # 全部照片的缩略图拼版（带编号，需 Pillow）
```

照片命名规则：`序号_平台照片ID.jpg`，序号即缩略图总览里的编号，方便对照挑选。

**关于画质**：下载的是平台**免费开放的最高清版本（带水印）**。不带水印的原图需要在平台内付费购买（单张或套餐），本工具不提供也不绕过付费——水印是摄影师的劳动成果标识，请多多支持。

## 常见问题

**Q：搜不到我的赛事？**
关键词写得太长容易匹配不上（比如官方名是「2026新宇彩板西青区半程马拉松」，你写「西青半程马拉松」反而匹配不到中间加了字的）。用短关键词（城市名 + 赛事类型），配合 `--year`。还是没有就加大 `--pages`，或去小程序确认平台是否收录了这场比赛。

**Q：参赛号搜出来 0 张？**
① 检查号码（字母大小写、0/O、1/I、空格）；② 赛后才几小时可能还没上传，等等再试；③ 用 `--list-events` 确认赛事 ID 没选错（同城常有欢乐跑/半马多个赛事）。

**Q：下载的为什么带水印？能去水印吗？**
带水印的是平台免费最高清版；无水印原图需付费购买。去水印请自行评估法律与道德风险——水印是摄影师的权益标识，本工具不对去水印行为背书。

**Q：报 `sign错误` / `-100`？**
检查是否改过脚本里的 `OSS_SIGN_SECRET`；本工具已按平台最新版前端复刻签名（含 uid 必须非空的坑）。平台接口偶发波动，重跑即可。

**Q：想下载视频？**
本赛事若平台标记 `video: 0` 说明没有视频；部分赛事的视频搜索接口已暂停服务（返回 `-10000`），这是平台侧限制，与工具无关。

**Q：速度慢 / 被限流？**
调大 `--workers`（如下载慢）或 `--delay`（如 API 报错多）。人脸检测阶段要对每张照片上传+检测，是主要耗时，属正常。

**Q：支持其他平台吗（如跑步维生素、混沌影像）？**
目前只支持爱云动/悦动拍系。欢迎参照 [docs/原理说明.md](docs/原理说明.md) 的逆向方法自行扩展，PR 欢迎。

更多问题见 [docs/常见问题.md](docs/常见问题.md)。
